secrets-scanner

Segredos e dados pessoais (CPF/CNPJ) em código e no histórico do git
Modo demonstração: todos os dados desta pasta são falsos, gerados na hora.
Tudo roda no seu computador: nada é enviado para a internet.
Escolha uma pasta e clique em Varrer.
É heurística: “nada encontrado” não prova que não há segredos, e a ferramenta não verifica se uma chave ainda está ativa.
